## 1. 项目概况

校园活动管理平台面向校园活动的「发现—报名—签到—统计」全链路，采用一个后端服务、三个前端入口的形态：

- **微信小程序**：学生浏览活动、报名、取消、扫码签到、查看消息；
- **组织者工作台**（同一小程序内）：学生会/社团发布活动、提交审核、审核报名、展示签到码、补签、查看统计；
- **管理后台**：团委审核活动、管理活动与用户、查看操作日志与工作台指标。

| 指标 | 数值 |
| --- | --- |
| 后端规模 | 113 个 Java 主代码文件，44 个 REST 接口 |
| 数据库 | 12 张表，4 类角色，活动/报名各 7 个状态 |
| 前端规模 | 小程序 13 个页面，管理后台 6 个视图，5438 行 TS/Vue |
| 技术栈 | Spring Boot 4.1.1、Spring Security 7、Spring Data Redis、MyBatis-Plus 3.5.18.1、MySQL 8、Redis、uni-app（Vue3）、Element Plus |
| 验证方式 | `mvn test` 20 个用例 + `scripts/smoke.sh` 33 项端到端断言 |

## 4. 文档约定

1. 每份文档开头为文档信息表，其后为版本记录，结尾为「待确认事项」。
2. 章节编号为 `1`、`1.1`、`1.1.1` 三级；图题在图下方（`图 X-N 名称`），表题在表上方（`表 X-N 名称`）。
3. 功能编号 `FR-*`、业务规则 `BR-*`、接口 `API-*`、数据表 `T-*` 在全套文档中唯一且固定。
4. 事实口径以源码为最终依据：44 个接口、12 张表、113 个 Java 文件、13 个小程序页、6 个后台视图、33 项冒烟断言、20 个自动化测试用例、5438 行前端代码；[_写作基线.md](_写作基线.md) 的 v1.0 数字为扩展前口径，差异见 12 号文档。
5. 图中不出现编造的版本号、IP、性能实测值；性能指标标注为「设计目标」。
6. 各章与图的逐节对应见 [_文档目录与配图对照表.md](_文档目录与配图对照表.md)；以下划线开头的 `_写作基线.md`、`_文档目录与配图对照表.md` 为内部参考，不计入 13 份正式文档。
