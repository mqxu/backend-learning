## 6. 插图与编号规则

1. **图随节走**：每张图放在首次论述它的那一节，图前一句“如图 X-N 所示”，图后 1–2 句解释；不要把所有图堆到附录。
2. **图号顺序**：图号按文档内出现顺序连续编号（06 的 7 张图已按正文顺序重排：图6-1 类图 → 图6-2 登录时序 → …… → 图6-7 签到码校验）。
3. **跨文档复用**：同一张图只在一处正式编号；其他文档写“见 XX 文档图 X-N”。D01、D02 允许双放（01/03、02/03），因为两份都是独立交付件。
4. **导出 Word/PDF**：按本表顺序排版；嵌入 PNG 2× 图，保留 SVG 源文件用于需要矢量时替换；每图不超过页宽，D07/D15 信息密度高，图后注明“可放大查看，完整字段/节点以表格为准”。
5. **灰度打印**：全部图使用 paper 预设，已做灰度抽查；新补的 UI 截图需检查文字对比度。
