## 1. 项目与目录

- 项目名：校园活动小程序（campus-activity），位于多模块教学仓库的 `15-cases/campus-activity/`。
- 三端结构：
  - `server/`：Spring Boot 后端，端口 **8016**
  - `app/`：uni-app + Vue3 + TS 小程序/H5，H5 预览端口 **5174**
  - `admin/`：Vue3 + Vite + Element Plus 管理后台，端口 **5173**
  - `scripts/smoke.sh`：33 项端到端冒烟断言
  - `docs/`：项目文档（`项目文档/` 13 份 + `教学包/` 本套 + `screenshots/` 32 张）
  - `deploy/`：本次新增的部署资产（systemd、Nginx、初始化脚本、云效流水线 YAML）
- 数据库：MySQL 库名 `campus_activity`，共 **12 张表**，建表与演示数据脚本：
  - `server/src/main/resources/db/schema.sql`
  - `server/src/main/resources/db/data.sql`

## 4. 关键接口与数量口径

- 扩展后 REST 接口总数 **44 个**：`/api/app` 19、`/api/org` 11、`/api/admin` 11、`/api/files` 2、`/api/ping` 1。
- 鉴权：`Authorization: Bearer <token>`；401 → HTTP 401 + `{"code":10001,...}`，403 → HTTP 403 + `{"code":10002,...}`。
- 学生端核心：`POST /api/app/auth/login`、`POST /api/app/auth/sms/send-code`、`POST /api/app/auth/sms/login`、`POST /api/app/auth/bind`、`GET /api/app/categories`、`GET /api/app/activities`、`GET /api/app/activities/{id}`、`POST /api/app/activities/{id}/signup`、`GET /api/app/signups`、`POST /api/app/checkin`、`POST /api/app/auth/logout`。
- 组织者：`/api/org/activities` CRUD、`/submit`、`/cancel`、`/signups`、`/checkin-qr`、`/checkin/manual`、`/stat`。
- 管理端：`/api/admin/auth/login`、`/logout`、`/dashboard`、`/activities`、`/activities/audit-list`、`/activities/{id}/audit`、`/activities/{id}/offline`、`/users`、`/organizations`、`/logs`。
- 文件：`POST /api/files/upload?bizType=activity-cover|org-logo|avatar|common`（multipart 字段 `file`）、`GET /api/files/storage`。
- 错误码分段：0 成功、10xxx 认证、20xxx 活动、30xxx 报名、40xxx 签到、50xxx 通用、60xxx 短信、70xxx 文件。
- Redis key：`campus:cache:*`、`campus:sms:code|interval|daily|fail:<phone>`、`campus:auth:blacklist:<jti>`、`campus:lock:activity-status-job`。

## 5. 标准命令（教程中每步都要给“预期输出”）

```bash
# 0. 环境自检
java -version          # 期望 21.x
mvn -v                 # 期望 3.9.x
node -v && pnpm -v     # 期望 Node 18+ / pnpm 8+
mysql --version        # 期望 8.0+
redis-server --version # 期望 6.2+

# 1. 数据库
mysql -uroot -p123456 -e "CREATE DATABASE IF NOT EXISTS campus_activity DEFAULT CHARSET utf8mb4"
cd server/src/main/resources/db
mysql -h127.0.0.1 -P3306 -uroot -p123456 campus_activity < schema.sql
mysql -h127.0.0.1 -P3306 -uroot -p123456 campus_activity < data.sql

# 2. 后端
cd server
mvn -o -DskipTests compile      # 首次无本地仓库时去掉 -o
mvn -o test                     # 20 个用例，期望 BUILD SUCCESS
mvn -o spring-boot:run          # 监听 8016
curl -s http://127.0.0.1:8016/api/ping
# 期望 {"code":0,"message":"ok","data":{"service":"campus-activity","status":"up"}}

# 3. 前端
cd app && pnpm install && pnpm dev:h5     # 5174
cd admin && pnpm install && pnpm dev      # 5173
# 构建（本地预览用根路径）
cd app && pnpm build:h5                   # app/dist/build/h5/
cd admin && pnpm build                    # admin/dist/
# 部署到 /app/ 子路径时必须带 VITE_BASE（app/vite.config.ts 已支持，已验证产物引用 /app/assets/）
cd app && VITE_BASE=/app/ pnpm build:h5

# 4. 验收
./scripts/smoke.sh                        # 期望“全部通过：33 项”
```

- 冒烟脚本默认 `BASE=http://127.0.0.1:8016/api`，可用 `BASE=... ./scripts/smoke.sh` 覆盖；第 7 节会清理手机号限流 key（依赖本机 `redis-cli -a abc123 -n 11`）。
- 测试数量口径：**5 个测试类 / 20 个用例**（ApiSmokeTest 5、SecurityAccessTest 5、FileUploadTest 5、SmsAuthTest 3、RedisCacheTest 2）。
- 冒烟数量口径：**8 个小节 / 33 项断言**（第 0 节健康检查不计入断言，第 1–7 节合计 33 项）。
- 页面数量口径：小程序 **14 页**、管理后台 **7 个视图**。

课程中的云效约定（写课时必须一致）：
- 每个小组一个云效项目（Scrum 模板），项目名 `CA-<组号>-校园活动`。
- 代码库 `campus-activity-<组号>`，主分支 `main`，集成分支 `develop`，任务分支 `feat/<任务号>-<简述>`、缺陷分支 `fix/<缺陷号>-<简述>`。
- 迭代命名：`Sprint 1`（第 1-2 次课）、`Sprint 2`（第 3-4 次课）。
- 需求拆分：至少 24 条需求/任务 + 8 条缺陷预案；任务必须关联需求；MR 必须关联任务号（如 `feat/CA-12-activity-list`）。
- 保护分支：`main`、`develop` 禁止直接 push；MR 至少 1 人评审通过才能合并。
- 流水线命名：`campus-activity-ci`，阶段：测试（`mvn test`）→ 构建（`mvn package`）→ 制品上传（jar + deploy.sh）→ 主机部署（ECS 主机组）。
- 发布：第 4 次课打 tag `v1.0.0`，在云效发布记录中关联流水线运行。
- 云效 UI 名称与免费权益可能随平台更新变化，文档中提示“以云效当前界面与官方文档为准”，教师课前用教师账号走一遍。

## 7. 部署契约（deploy/ 资产与文档必须一致）

| 项 | 约定 |
| --- | --- |
| 目标 | 阿里云 ECS（Alibaba Cloud Linux 3 或 Ubuntu 22.04，2C4G 起） |
| 安装目录 | `/opt/campus-activity/`（jar、uploads、web、logs） |
| 运行用户 | `campus`（非 root），环境变量文件 `/etc/campus-activity/env` |
| systemd 服务 | `campus-activity.service`，`ExecStart=/usr/bin/java $JAVA_OPTS -jar /opt/campus-activity/app.jar` |
| Nginx 站点 | `/etc/nginx/conf.d/campus-activity.conf` |
| 路由 | `/api/`、`/uploads/` → `127.0.0.1:8016`；`/` → 管理后台静态；`/app/` → 小程序 H5 静态 |
| 部署脚本 | `deploy/deploy.sh`，支持 `start|stop|restart|status`；`restart` 归档当前版本到 `releases/`（方式 B 保留运行中旧 jar） |
| 初始化脚本 | `deploy/init-server.sh`（安装 JDK21/MySQL8/Redis（发行版 6.x，建议 6.2+）/Nginx、建目录用户；数据库导入需 `IMPORT_DB=true` 或按 06 第 4 章手工执行） |
| 云效流水线 | `deploy/flow/campus-activity-pipeline.yaml`，含代码源/构建/制品/主机部署占位符 |
| 主机组 | 云效“主机组”接入 ECS（SSH 密钥），部署路径 `/opt/campus-activity/package.tgz` |
| 安全组 | 放行 22、80（HTTPS 则 443），数据库/Redis 不对公网开放 |
| 健康检查 | `curl -s http://127.0.0.1:8016/api/ping` 或 `http://<ECS-IP>/api/ping` |

部署生产注意：MySQL/Redis 密码、JWT 密钥、短信/OSS 凭证全部走 `/etc/campus-activity/env` 注入，不写进仓库；`campus.sms.expose-code=false`、`campus.dev-mode=false`（演示环境可临时保留 dev-mode 并说明风险）。

## 13. 部署包结构约定（deploy.sh 与流水线必须一致）

- 云效主机部署下载路径：`/opt/campus-activity/package.tgz`。
- `package.tgz` 解压后的根目录内容：
  - `app.jar`（= 后端 `campus-activity-server-1.0.0.jar`）
  - `web/admin/**`（管理后台构建产物）
  - `web/app/**`（小程序 H5 构建产物）
  - `deploy.sh`（部署脚本，支持 `start|stop|restart|status`；`restart` 归档当前版本到 `releases/`）
- 主机部署脚本（云效 Flow 中填写）：
  ```bash
  mkdir -p /opt/campus-activity
  tar zxvf /opt/campus-activity/package.tgz -C /opt/campus-activity/
  sh /opt/campus-activity/deploy.sh restart
  ```
- Nginx 静态目录：`/opt/campus-activity/web/admin`、`/opt/campus-activity/web/app`；上传目录 `/opt/campus-activity/uploads`；日志 `/opt/campus-activity/logs`。
- 流水线主路径：云效代码源 → 构建（JDK21 + Maven 测试/打包 + Node20 构建两端）→ 制品上传（app.jar、web/、deploy.sh）→ 主机部署。若云端 Node 构建网络受限，降级方案为本地构建前端后随制品上传（文档中给出）。
- H5 部署在 `/app/` 子路径：`VITE_BASE=/app/ pnpm run build:h5`（`app/vite.config.ts` 读取该环境变量，默认 `/`），产物 `index.html` 必须引用 `/app/assets/...`；本地开发与预览不加该变量。
