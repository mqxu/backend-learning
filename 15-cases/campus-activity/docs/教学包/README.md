# 教学包 README · 校园活动小程序全栈项目课程

> 16 学时（4 次课 × 4 学时）+ 课后小组任务的课程教学包：学生在阿里云云效平台上以 4–5 人小组完成「校园活动小程序」全栈项目，从环境搭建走到 ECS 上线与答辩。
> 本 README 是**导览**：告诉你有哪些文件、教师怎么备课、学生怎么自学、30 分钟怎么快速体验、改了事实要同步哪里。

## 这是什么

| 项 | 内容 |
| --- | --- |
| 项目 | 校园活动小程序（`campus-activity`）：学生浏览/报名/签到，组织者发布/核销，团委审核/统计 |
| 技术栈 | Spring Boot 4.1.1 + MyBatis-Plus 3.5.18.1 + MySQL 8 + Redis + Spring Security 7；uni-app（Vue3）+ Vue3/Element Plus；短信验证码与文件上传（Mock/本地默认，可切真实通道与 OSS） |
| 规模口径 | 44 个 REST 接口、12 张表、小程序 14 页、管理后台 7 个视图、20 个后端测试用例、33 项冒烟断言 |
| 课程结构 | 4 次课 × 4 学时（16 学时）+ 每次课后 2–3 小时小组任务 |
| 平台 | 阿里云云效（Projex / Codeup / Flow / Testhub，Packages 与效能洞察选讲） |
| 验证状态 | 本地开发/测试/构建完全可验证；云效 UI 与 ECS 真实部署需账号与服务器（未在本机端到端验证，见 08 号报告） |
| 版本 | v1.0（2026-11-11） |

### 路径 B：有环境动手版（约 30 分钟，需本机 MySQL/Redis）

前置：已装 JDK21、Maven、MySQL8、Redis6.2+（版本以 07 号第 2 节为准）；数据库未初始化也可，第 2 步会建。

```bash
# 1) 起 Redis（database 11，密码 abc123）
redis-cli -a abc123 --no-auth-warning -n 11 ping        # 期望 PONG

# 2) 建库 + 导入结构/演示数据（12 张表）
mysql -uroot -p123456 -e "CREATE DATABASE IF NOT EXISTS campus_activity DEFAULT CHARSET utf8mb4"
cd server/src/main/resources/db
mysql -h127.0.0.1 -P3306 -uroot -p123456 campus_activity < schema.sql
mysql -h127.0.0.1 -P3306 -uroot -p123456 campus_activity < data.sql

# 3) 起后端（新终端）
cd server && mvn -o -DskipTests compile && mvn -o spring-boot:run

# 4) 验证（新终端）
curl -s http://127.0.0.1:8016/api/ping
# 期望 {"code":0,"message":"ok","data":{"service":"campus-activity","status":"up"}}
curl -s http://127.0.0.1:8016/api/app/categories      # 期望 6 个分类
curl -s -X POST http://127.0.0.1:8016/api/app/auth/sms/send-code \
  -H 'Content-Type: application/json' -d '{"phone":"13800000003"}'
# 期望 data.mockCode 返回 6 位验证码

# 5) 打开接口文档：http://127.0.0.1:8016/swagger-ui.html
```

| 时间 | 动作 | 预期 |
| --- | --- | --- |
| 0–5 | 起 Redis、建库导数据 | 12 张表、演示数据成功导入 |
| 5–15 | 起后端 + 3 条 curl | `code=0`；6 个分类；`mockCode` 有值 |
| 15–20 | 打开 Swagger，数一下 `/api/app` 分组 | 44 个接口可见 |
| 20–30 | 打开 05 号第 3.1 节，在云效里建一个 `CA-01-校园活动` 项目 | 项目创建成功、看板可见 |

> 30 分钟快速体验**不包含**前端启动（5174/5173 需装依赖）与全量测试（`mvn test` 约 2–5 分钟）、冒烟脚本（需 jq/redis-cli）。完整验证按 07 号第 5 节命令执行。
