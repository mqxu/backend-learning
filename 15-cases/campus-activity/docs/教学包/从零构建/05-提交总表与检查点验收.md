## 1 使用方式（三种）

### 方式 A：直接克隆 bundle 回放（推荐自学/备课）

```bash
# bundle 在 docs/教学包/从零构建/campus-activity-tutorial.bundle
git clone -b tutorial/from-zero campus-activity-tutorial.bundle campus-activity-from-zero
cd campus-activity-from-zero
git log --oneline        # 65 个提交，后端/小程序/后台交错，代码逐步长出来
git show <commit>        # 看任意一步完整 diff
```

### 方式 B：把分支接入现有仓库（教师推到云效）

```bash
git fetch /path/to/campus-activity-tutorial.bundle \
  'refs/heads/tutorial/from-zero:refs/heads/tutorial/from-zero' \
  'refs/tags/tutorial-v1.0.0:refs/tags/tutorial-v1.0.0'
git checkout tutorial/from-zero
```

### 方式 C：推到云效 Codeup 供全班使用

```bash
git remote add yunxiao https://codeup.aliyun.com/<组织>/<仓库>.git
git push yunxiao tutorial/from-zero --tags
```
