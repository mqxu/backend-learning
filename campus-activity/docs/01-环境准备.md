# 01 环境准备

## 需要装什么

| 软件 | 版本要求 | 用途 |
| --- | --- | --- |
| JDK | 21（17 以上即可） | 编译运行后端 |
| Maven | 3.8+ | 构建后端 |
| Node.js | 18+ | 小程序与管理后台 |
| MySQL | 8.0+ | 数据库 |
| Docker（可选） | 任意近期版本 | 起一个独立的 MySQL，不占用本机 3306 |
| 微信开发者工具 | 最新稳定版 | 小程序真机与模拟器调试 |

命令行确认版本：

```bash
java -version
mvn -v
node -v
npm -v
mysql --version
```

## 准备数据库

推荐用 Docker 起一个独立实例，端口 3308，避免与本机已有 MySQL 冲突：

```bash
docker run -d --name campus-mysql \
  -p 3308:3306 \
  -e MYSQL_ROOT_PASSWORD='Campus@2026' \
  -e MYSQL_DATABASE=campus_activity \
  -e TZ=Asia/Shanghai \
  mysql:8 --character-set-server=utf8mb4 --collation-server=utf8mb4_0900_ai_ci
```

首次启动需要十几秒初始化，之后验证：

```bash
mysql -h127.0.0.1 -P3308 -uroot -p'Campus@2026' -e "select 1"
```

如果使用本机已安装的 MySQL，把端口和密码换成自己的，并同步修改 `server/src/main/resources/application.yml`：

```yaml
spring:
  datasource:
    url: jdbc:mysql://127.0.0.1:3308/campus_activity?useUnicode=true&characterEncoding=utf8&serverTimezone=Asia/Shanghai&useSSL=false&allowPublicKeyRetrieval=true
    username: root
    password: Campus@2026
```

`allowPublicKeyRetrieval=true` 不能省：MySQL 8 默认使用 `caching_sha2_password`，JDBC 获取公钥需要这个参数。

## 准备前端依赖

npm 默认源在国内较慢，建议配置镜像：

```bash
npm config set registry https://registry.npmmirror.com
```

`app` 与 `admin` 两个目录分别安装：

```bash
cd app && npm install
cd ../admin && npm install
```

uni-app 依赖包较多，首次安装通常需要三到五分钟。

## 微信开发者工具（真机调试时）

1. 新建项目，目录选择 `app/dist/dev/mp-weixin`（先执行 `npm run dev:mp-weixin` 生成）。
2. AppID 可以先用测试号，或填自己的小程序 AppID。
3. 详情 → 本地设置 → 勾选「不校验合法域名、web-view（业务域名）、TLS 版本以及 HTTPS 证书」，否则请求 `http://127.0.0.1:8080` 会被拦截。
4. 详情 → 本地设置 → 勾选「将 JS 编译成 ES5」关闭也可以，当前基础库支持现代语法。

## 检查清单

在开始下一步前，确认：

- `java -version` 输出 21
- `mysql -h127.0.0.1 -P3308 -uroot -p'Campus@2026' -e "select 1"` 返回 1
- `app/node_modules` 与 `admin/node_modules` 都存在
- 8080、5173、5174 三个端口没有被其他程序占用

端口占用检查：

```bash
lsof -nP -iTCP:8080 -sTCP:LISTEN
```
