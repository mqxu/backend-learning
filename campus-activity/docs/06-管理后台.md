# 06 管理后台

## 技术栈

Vue3 + Vite + Element Plus + Vue Router + TypeScript。

类型定义集中在 `src/types/api.ts`（`ApiResult`、`PageResult`、`ActivityItem`、`UserInfo`、`AuditRecord` 等），接口函数全部带泛型返回。

类型检查：

```bash
pnpm type-check
```

## 启动

```bash
cd admin
pnpm install
pnpm run dev
```

访问 `http://127.0.0.1:5173`，账号 `admin` / `Admin@123`。

`vite.config.js` 配置了 `/api` 代理：

```js
server: {
  port: 5173,
  proxy: { '/api': { target: 'http://127.0.0.1:8080', changeOrigin: true } }
}
```

所以前端代码里请求写 `/api/admin/...`，不需要处理跨域。

## 页面与接口

| 页面 | 路由 | 接口 |
| --- | --- | --- |
| 登录 | `/login` | `POST /api/admin/auth/login` |
| 工作台 | `/dashboard` | `GET /api/admin/dashboard` |
| 活动审核 | `/audit` | `GET /api/admin/activities/audit-list`、`POST /api/admin/activities/{id}/audit` |
| 活动管理 | `/activities` | `GET /api/admin/activities`、`POST /api/admin/activities/{id}/offline` |
| 用户管理 | `/users` | `GET /api/admin/users`、`POST /api/admin/users/{id}/roles`、`GET /api/admin/organizations` |
| 操作日志 | `/logs` | `GET /api/admin/logs` |

活动详情复用小程序端的公开接口 `GET /api/app/activities/{id}`，审核时用抽屉展示，`content` 字段是纯文本，用 `white-space: pre-wrap` 保留换行。

## 登录态

登录成功后把 token 存 `localStorage`，请求拦截器统一加头：

```js
config.headers.Authorization = `Bearer ${token}`
```

响应里 `code !== 0` 用 `ElMessage.error` 提示；HTTP 401 清空 token 并跳登录页。

## 审核流程

待审核列表按提交时间正序，方便先来先审。两条操作路径：

- 通过：二次确认后调 `audit` 接口，`pass: true`
- 驳回：弹窗填理由，必填校验，调 `audit` 接口，`pass: false, reason`

驳回理由会写入 `activity.reject_reason`，组织者在小程序「我的活动」能看到并修改后重新提交。

## 构建

```bash
pnpm build
```

产物在 `admin/dist`，直接放到 Nginx 的静态目录即可，部署细节见 `08-部署上线.md`。
