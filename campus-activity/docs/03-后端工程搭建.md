# 03 后端工程搭建

## 包结构

```
com.campus.activity
├── CampusActivityApplication      启动类，@MapperScan + @EnableScheduling
├── common      Result / PageResult / ResultCode / BizException / 全局异常 / 登录上下文 / 时间工具
├── config      CampusProperties / MyBatis-Plus 配置 / Web 配置 / 演示数据初始化
├── security    JwtUtil / AuthInterceptor / @RequireLogin / @RequireRole
├── entity      与表一一对应的实体
├── mapper      MyBatis-Plus Mapper，复杂 SQL 用注解写在接口上
├── dto           入参对象
├── vo            出参对象
├── service     业务逻辑
├── controller  app（学生） / org（组织者） / admin（后台）
└── job         定时任务
```

分层边界：Controller 只做参数接收和调用，不写业务判断；Service 不出现 `HttpServletRequest`；Mapper 只做数据访问。

## pom 关键依赖

```xml
<parent>
    <groupId>org.springframework.boot</groupId>
    <artifactId>spring-boot-starter-parent</artifactId>
    <version>4.1.1</version>
</parent>
```

三个容易装错的地方：

```xml
<!-- 1. Spring Boot 4 必须用 boot4 版 starter，boot3 版自动配置不生效，启动后 Mapper 注入为空 -->
<dependency>
    <groupId>com.baomidou</groupId>
    <artifactId>mybatis-plus-spring-boot4-starter</artifactId>
    <version>3.5.18.1</version>
</dependency>

<!-- 2. 分页插件从 3.5.9 起拆成独立模块，不加这行找不到 PaginationInnerInterceptor -->
<dependency>
    <groupId>com.baomidou</groupId>
    <artifactId>mybatis-plus-jsqlparser</artifactId>
    <version>3.5.18.1</version>
</dependency>

<!-- 3. 只取 BCrypt 做密码哈希，不引入整套 Spring Security -->
<dependency>
    <groupId>org.springframework.security</groupId>
    <artifactId>spring-security-crypto</artifactId>
</dependency>
```

JWT 用 `jjwt-api` + `jjwt-impl` + `jjwt-jackson` 三个包，版本 0.13.0；接口文档用 `springdoc-openapi-starter-webmvc-ui` 3.2.0（对应 Spring Boot 4 的 3.x 分支）。

MySQL 驱动 `com.mysql:mysql-connector-j` 由 Spring Boot BOM 管理版本，不写版本号。

## 配置文件

`application.yml` 里的自定义配置项：

```yaml
campus:
  dev-mode: true                 # 打开后用 devOpenId 登录，不请求微信服务器
  jwt:
    secret: campus-activity-demo-secret-key-change-in-production-2026
    access-token-hours: 2
  wechat:
    app-id: ${WX_APPID:}
    app-secret: ${WX_SECRET:}
  checkin:
    secret: campus-checkin-demo-secret-2026
    slice-seconds: 30            # 签到码轮换周期
    tolerance-slices: 2          # 允许过期的时间片数量
    open-before-minutes: 30      # 活动开始前多久开放签到
    close-after-minutes: 30      # 活动结束后多久关闭签到
```

对应 `config/CampusProperties`，用 `@ConfigurationProperties(prefix = "campus")` 绑定。生产环境把两个 secret 换成环境变量，`dev-mode` 改成 `false`。

## 统一响应

`common/Result` 是 record：

```java
public record Result<T>(int code, String message, T data) {
    public static <T> Result<T> ok(T data) { return new Result<>(0, "ok", data); }
    public static <T> Result<T> fail(ResultCode rc) { return new Result<>(rc.getCode(), rc.getMessage(), null); }
}
```

业务错误码集中在 `ResultCode` 枚举，按模块分段：

| 段 | 范围 | 示例 |
| --- | --- | --- |
| 认证 | 10001-10099 | 10001 未登录、10003 请先绑定学号 |
| 活动 | 20001-20099 | 20001 活动不存在、20002 状态不支持 |
| 报名 | 30001-30099 | 30001 名额已满、30002 已报名 |
| 签到 | 40001-40099 | 40001 签到码无效、40003 已签到 |

业务异常统一抛 `BizException`，返回值仍是 HTTP 200，前端只看 `code`。参数校验失败返回 400，未登录返回 401，无权限返回 403，未捕获异常返回 500，这四种由 `GlobalExceptionHandler` 和拦截器处理。

## 登录态

`security/JwtUtil` 负责签发和解析，载荷是 `userId`、`role`、`orgId`、`nickname`：

```java
Jwts.builder()
    .subject(String.valueOf(user.getId()))
    .claim("role", user.getRole())
    .claim("orgId", user.getOrgId())
    .expiration(Date.from(Instant.now().plus(2, ChronoUnit.HOURS)))
    .signWith(key)
    .compact();
```

`security/AuthInterceptor` 拦截 `/api/**`：

- 带 `Authorization: Bearer <token>` 就解析并放入 `UserContext`（ThreadLocal）
- 方法或类上有 `@RequireLogin` 且没有登录态 → 401
- 方法或类上有 `@RequireRole({"ORGANIZER"})` 且角色不符 → 403
- 请求结束清空 ThreadLocal

不需要登录的接口不加注解，但带了 token 依然能拿到当前用户。活动详情就靠这一点返回「我的报名状态」。

拦截器写 401/403 响应时没有用 Jackson，直接拼固定结构的 JSON。Spring Boot 4 默认的 JSON 库换成了 Jackson 3（`tools.jackson`），拦截器里注入 `ObjectMapper` 需要区分版本，拼字符串省掉这层依赖。

## 分页

```java
@Bean
public MybatisPlusInterceptor mybatisPlusInterceptor() {
    MybatisPlusInterceptor interceptor = new MybatisPlusInterceptor();
    PaginationInnerInterceptor pagination = new PaginationInnerInterceptor(DbType.MYSQL);
    pagination.setMaxLimit(50L);   // 单页上限，防止 size=100000 拉全表
    interceptor.addInnerInterceptor(pagination);
    return interceptor;
}
```

Controller 接收 `page` / `size`，Service 用 `new Page<>(page, size)`，出参统一 `PageResult`：

```json
{ "records": [], "total": 42, "page": 1, "size": 10 }
```

## 启动

```bash
cd server
mvn spring-boot:run -Dspring-boot.run.arguments="--server.port=8080"
```

启动成功后：

- 健康检查 `GET http://127.0.0.1:8080/api/ping`
- 接口文档 `http://127.0.0.1:8080/swagger-ui.html`

启动时控制台会打印一条 `[订阅消息预留]` 日志，这是消息发送出口的占位实现，属于正常输出。
