# 08 部署上线

## 一、打包

后端：

```bash
cd server
mvn clean package -DskipTests
```

产物 `server/target/campus-activity-server-1.0.0.jar`，自带 Tomcat，直接 `java -jar` 即可运行。

前端：

```bash
cd app && npm run build:h5          # 产物 dist/build/h5
cd admin && npm run build           # 产物 dist
```

小程序的 `dist/build/mp-weixin` 用微信开发者工具上传，不走服务器。

## 二、服务器准备

| 组件 | 版本 | 说明 |
| --- | --- | --- |
| JDK | 21 | 运行 jar |
| MySQL | 8.0+ | 生产库 |
| Nginx | 1.20+ | 反向代理与静态资源 |
| 操作系统 | Linux x86_64 | |

创建数据库并导入结构：

```bash
mysql -uroot -p -e "create database campus_activity default character set utf8mb4 collate utf8mb4_0900_ai_ci"
mysql -uroot -p campus_activity < db/schema.sql
```

生产环境不要导入 `data.sql`，那是演示数据。需要初始管理员时手工插入一条：

```sql
insert into sys_user (id, open_id, nickname, role, username, password_hash, status, create_time, update_time, deleted)
values (1, 'admin:admin', '系统管理员', 'ADMIN', 'admin', '<你的 bcrypt 哈希>', 1, now(), now(), 0);
```

哈希用 `htpasswd -bnBC 10 "" '你的密码'` 生成。

## 三、环境变量

不要把这些写死在配置文件里：

| 变量 | 说明 |
| --- | --- |
| `SPRING_DATASOURCE_URL` | 生产库连接串 |
| `SPRING_DATASOURCE_USERNAME` | 数据库账号 |
| `SPRING_DATASOURCE_PASSWORD` | 数据库密码 |
| `WX_APPID` | 小程序 AppID |
| `WX_SECRET` | 小程序 AppSecret |
| `CAMPUS_JWT_SECRET` | JWT 签名密钥，至少 32 字符，换掉默认值 |
| `CAMPUS_CHECKIN_SECRET` | 签到码签名密钥 |
| `CAMPUS_DEV_MODE` | 生产必须为 `false` |

Spring 的宽松绑定会把 `CAMPUS_JWT_SECRET` 映射到 `campus.jwt.secret`，不用改配置文件。

## 四、启动服务

用 systemd 托管：

```ini
# /etc/systemd/system/campus-activity.service
[Unit]
Description=Campus Activity Server
After=network.target mysql.service

[Service]
Type=simple
User=www-data
WorkingDirectory=/opt/campus-activity
EnvironmentFile=/opt/campus-activity/env
ExecStart=/usr/bin/java -Xms512m -Xmx1024m -jar /opt/campus-activity/campus-activity-server-1.0.0.jar
Restart=always
RestartSec=5
StandardOutput=append:/var/log/campus-activity/app.log
StandardError=append:/var/log/campus-activity/error.log

[Install]
WantedBy=multi-user.target
```

`/opt/campus-activity/env` 每行一个环境变量：

```
SPRING_DATASOURCE_PASSWORD=实际密码
CAMPUS_DEV_MODE=false
CAMPUS_JWT_SECRET=换成一串随机字符
WX_APPID=wx1234567890abcdef
WX_SECRET=实际密钥
```

权限收紧到 600，然后：

```bash
systemctl daemon-reload
systemctl enable --now campus-activity
systemctl status campus-activity
```

## 五、Nginx

```nginx
server {
    listen 80;
    server_name activity.example.edu.cn;
    return 301 https://$host$request_uri;
}

server {
    listen 443 ssl http2;
    server_name activity.example.edu.cn;

    ssl_certificate     /etc/nginx/ssl/activity.pem;
    ssl_certificate_key /etc/nginx/ssl/activity.key;

    # 管理后台
    root /opt/campus-activity/admin;
    index index.html;

    location / {
        try_files $uri $uri/ /index.html;
    }

    # 后端接口
    location /api/ {
        proxy_pass http://127.0.0.1:8080;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
        proxy_read_timeout 60s;
    }

    client_max_body_size 10m;
}
```

小程序端如果用 H5 版本，把 `app/dist/build/h5` 放到另一个 server 或子目录；纯小程序不需要。

前端生产包的请求地址要改成线上域名：`app/src/utils/request.js` 里把 `BASE_URL` 的 `#ifndef H5` 分支换成 `https://activity.example.edu.cn/api`，重新构建。

## 六、小程序配置

微信公众平台 → 开发 → 开发管理 → 服务器域名：

- request 合法域名：`https://activity.example.edu.cn`
- 域名必须 HTTPS、已备案、不能带端口

同一页面的「业务域名」不需要配，除非用到 web-view。

上线前把 `dev-mode` 关掉，登录才会真正走 `code2session`。

## 七、备份

每天备份数据库，保留 30 天：

```bash
# /opt/campus-activity/backup.sh
#!/usr/bin/env bash
set -e
DATE=$(date +%F)
mysqldump -uroot -p"$DB_PASSWORD" --single-transaction --routines campus_activity \
  | gzip > /backup/campus-$DATE.sql.gz
find /backup -name 'campus-*.sql.gz' -mtime +30 -delete
```

```cron
0 3 * * * /opt/campus-activity/backup.sh
```

`--single-transaction` 保证备份期间不锁表。

## 八、上线检查清单

- [ ] `CAMPUS_DEV_MODE=false`，登录走真实微信链路
- [ ] JWT 与签到码密钥已更换，不是配置文件里的默认值
- [ ] 数据库密码通过环境变量注入，`env` 文件权限 600
- [ ] 关闭 Swagger：`springdoc.api-docs.enabled=false`、`springdoc.swagger-ui.enabled=false`
- [ ] 关闭 SQL 日志：去掉 `mybatis-plus.configuration.log-impl`
- [ ] 收紧 CORS：`WebMvcConfig` 里的 `allowedOriginPatterns("*")` 改成实际域名，或直接删掉（同域部署不需要）
- [ ] HTTPS 证书有效期确认，配置自动续期
- [ ] 小程序 request 合法域名已添加，域名已备案
- [ ] 定时任务在跑：日志里能看到「状态推进完成」
- [ ] `curl https://活动域名/api/ping` 返回 code 0
- [ ] 备份脚本执行过一次并确认产物可解压
