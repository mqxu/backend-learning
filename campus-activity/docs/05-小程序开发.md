# 05 小程序开发

技术栈：uni-app（Vue3）+ TypeScript + Vite。所有页面使用 `<script setup lang="ts">`，接口返回结构在 `src/types.ts` 中统一定义。

## 工程结构

```
app/
├── vite.config.js        dev 端口 5174，/api 代理到 8080
├── package.json          只保留 h5 与 mp-weixin 两个平台依赖
└── src/
    ├── App.vue           全局样式（卡片、按钮、标签等公共类）
    ├── pages.json        页面注册与 tabBar
    ├── main.js
    ├── types.ts          接口数据结构定义

    ├── utils/

    │   ├── api.ts        接口清单与状态文案映射
```

## 请求封装

小程序里不能写相对路径，H5 走 vite 代理，两者用条件编译切换：

```js
// #ifdef H5
const BASE_URL = '/api'
// #endif
// #ifndef H5
const BASE_URL = 'http://127.0.0.1:8080/api'
// #endif
```

`request.js` 统一处理四件事：

- 自动带 `Authorization: Bearer <token>`
- `code === 0` 取 `data` 返回，否则 `uni.showToast` 提示并 reject
- 401 清 token 并提示重新登录
- 403 提示没有权限

页面里不写 `uni.request`，一律调 `api.js` 里声明好的方法：

```js
const page = await api.activities({ page: 1, size: 10, categoryId: 1002 })
```

## 登录与身份

小程序正常流程是 `uni.login` 换 code，但 H5 调试没有微信环境。`utils/auth.js` 用条件编译区分：

- 编译到 `MP-WEIXIN`：走 `uni.login`
- 其他平台：用 `devOpenId`，默认 `mock-student-1`

```js
// #ifndef MP-WEIXIN
const devOpenId = uni.getStorageSync('campus_dev_openid') || 'mock-student-1'
payload = { devOpenId, nickname: '张小明' }
// #endif
```

「我的 → 切换测试身份」可以切成 `mock-student-1`、`mock-student-2`、`mock-organizer-1`，切换后清 token 重新进入，用来演示同一活动下不同身份的行为。

首页 `onShow` 会静默登录一次，失败不阻塞浏览；真正需要登录的操作（报名、收藏、签到）调 `ensureLogin()`，未登录先登录，未绑定学号跳绑定页。

## 页面要点

### 首页与列表

首页三个区块的数据一次并发拉取：

```js
const [cats, hotList, page] = await Promise.all([
  api.categories(),
  api.hotActivities(),
  api.activities({ page: 1, size: 10 })
])
```

列表用 `onReachBottom` 分页，`hasMore` 由 `list.length < total` 决定。分类跳转通过 `uni.setStorageSync('filter_category', id)` 传参给 tabBar 页面——`switchTab` 不支持 query 参数，这是绕开限制的常用做法。

### 详情页

底部按钮文案由后端算好放在 `actionText`，前端只负责映射动作，避免前后端各写一套状态判断：

| actionText | 点击行为 |
| --- | --- |
| 立即报名 | 无自定义字段直接弹确认框，有字段跳报名表单 |
| 已报名 / 已签到 / 候补中 / 报名待审核 | 跳我的报名 |
| 名额已满 / 报名未开始 / 活动已结束 | 仅提示 |

报名进度条按 `signedCount / capacity` 计算，`capacity` 为 0 时显示不限人数。

### 报名表单

自定义字段存在活动的 `form_fields`（JSON 数组），格式：

```json
[{ "key": "song", "label": "演唱曲目", "type": "TEXT", "required": true }]
```

`type` 支持 `TEXT`、`SINGLE`、`MULTI`，后两者需要 `options` 数组。提交时把答案序列化成 JSON 字符串放进 `formData`，后端原样存库。

### 扫码签到

学生端调 `uni.scanCode` 拿到二维码内容，再带上定位提交：

```js
uni.scanCode({
  success: async (res) => { await submit(res.result) }
})
```

定位用 `uni.getLocation({ type: 'gcj02' })`，拿不到也允许提交——服务端按活动的 `checkinType` 决定是否校验距离，只有「扫码 + 定位」模式才要求。

H5 没有扫码能力，页面保留手动粘贴签到码的入口，方便在浏览器里跑通全流程。

### 核销页

组织者打开核销页调用 `checkinQr`，页面展示签到码字符串与倒计时，30 秒自动刷新：

```js
timer = setInterval(() => {
  countdown.value -= 1
  if (countdown.value <= 0) refresh()
}, 1000)
```

离开页面要 `clearInterval`，否则定时器会在后台持续请求。

当前版本把签到码作为文本展示并提供复制，学生端用手动粘贴或扫码提交。要在现场直接扫二维码，在核销页加一个二维码组件即可：用 `uqrcodejs` 之类的库把 `data.token` 画到 canvas 上，学生扫码内容就是 token 本身，其它逻辑不用改。

## 跑起来

### 浏览器预览

```bash
cd app
pnpm install
pnpm run dev:h5
```

访问 `http://127.0.0.1:5174`。`/api` 请求由 vite 代理到 8080，不需要处理跨域。

### 微信开发者工具

```bash
pnpm run dev:mp-weixin
```

产物在 `app/dist/dev/mp-weixin`，用开发者工具导入这个目录。

导入后要做两件事，否则请求全部失败：

1. 详情 → 本地设置 → 勾选「不校验合法域名、web-view（业务域名）、TLS 版本以及 HTTPS 证书」
2. 真机调试时把 `request.js` 里的 `BASE_URL` 从 `127.0.0.1` 改成电脑的局域网 IP，例如 `http://192.168.1.10:8080/api`，并确认手机与电脑在同一网段

正式发布前把 `BASE_URL` 换成备案过的 HTTPS 域名。

### 构建生产包

```bash
pnpm build:h5          # 产物 dist/build/h5
pnpm build:mp-weixin   # 产物 dist/build/mp-weixin
pnpm type-check        # vue-tsc 类型检查，应为零错误
```

小程序包用开发者工具上传，提交审核时类目选「教育 → 校园服务」。
